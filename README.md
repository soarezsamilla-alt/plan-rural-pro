# Plan Rural Pro

Crie do zero uma landing page de venda chamada "Plan Rural", seguindo EXATAMENTE esta ordem de seções (idêntica à versão brasileira de referência): badge de urgência/visualização no topo → hero → 4 cards de benefício → galeria de amostras → comparação antes/depois → "tudo o que você vai receber" + bônus (6 cards) → CTA → galeria de amostras (repetição) → passo a passo (4 etapas) → depoimentos → planos de preço (2, lado a lado) → seção de Instagram → garantia → FAQ → rodapé.

Regras obrigatórias:

Todo o texto deve estar em espanhol latino-americano neutro (não usar "vosotros", "vale", "ordenador" ou outros termos característicos do espanhol da Espanha — mantenha "tú", "computadora", "celular", como já está na copy abaixo).
Não altere a copy: use o texto exatamente como está escrito abaixo, especialmente a headline e a subheadline do hero, que devem permanecer literalmente as mesmas.
Revise a diagramação do texto ao montar o layout — sem erros de digitação, sem quebra de acentuação, sem espaçamento quebrado, sem caracteres cortados entre uma seção e outra.
Nas seções de amostras e de bônus, apenas insira os placeholders de imagem [IMAGEM: ...] exatamente onde indicado — as imagens reais (mockups) serão adicionadas manualmente depois, não é necessário gerar ou sugerir imagens para esses dois blocos.
